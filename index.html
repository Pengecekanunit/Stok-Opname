TOTAL KESELURUHAN HARGA: -

1. Impor Master Unit dari Excel

Pilih file Excel master data unit motor untuk dimasukkan ke dalam database perangkat ini.

2. Impor Warehouse Pendukung (File ke-2 s/d ke-6)

Unggah file Excel pendukung (ke-2 s/d ke-6). Sistem membaca kolom Warehouse/Lokasi lalu mencocokkannya dengan unit pada File ke-1 (Master) berdasarkan Nomor Rangka & Nomor Mesin. Unit yang tidak ditemukan / tidak cocok di File ke-1 tidak akan diabaikan — unit tersebut otomatis ditambahkan dengan status Belum Opname, Warehouse Master bernilai "Tidak Terdata di File 1", dan keterangan lokasi mengikuti nomor file (Warehouse 2, Warehouse 3, ... s/d Warehouse 6) agar segera dapat diperiksa di lapangan. Data master & hasil opname yang sudah ada tidak akan ikut terhapus / berubah.

3. Download Hasil Stok Opname & Foto Bukti

Unduh data hasil opname dalam bentuk file Excel (.xlsx) atau unduh seluruh foto fisik unit sekaligus (ZIP).

4. Bersihkan Database Perangkat

Hapus seluruh data master dan hasil opname yang tersimpan di browser ini.

📖 4 Fitur Utama
1

Opname Unit

Pemeriksaan Fisik Unit

  1. 1 Cari Unit: Masukkan nomor mesin atau nomor rangka (lengkap / beberapa angka) pada kolom pencarian.
  2. 2 Ambil Foto: Foto nomor rangka/mesin (serta KSU jika ada) via kamera/galeri.
  3. 3 Simpan Data: Pilih "Ada/Sesuai", isi checklist KSU pada pop-up kelengkapan unit, lalu klik "Simpan & Sinkronkan".
2

Rekap Audit KSU

Rekapitulasi Kelengkapan & Stok Gudang

a Berita Acara Audit: Menampilkan rekap KSU terpasang & fisik gudang secara otomatis, lengkap dengan kesimpulan selisih. Setelah selesai, klik "Download PDF" (atau "Download Excel" untuk pembaruan data).
b Barang Minus KSU: Khusus rekap KSU yang bernilai minus. Wajib menginput Harga Satuan & Kode Part, lalu unduh laporan dalam bentuk PDF/Excel.
c Input Fisik Gudang: Untuk menginput stok KSU loose/eceran di gudang/pos.
Pilih Kategori Item → Pilih Klasifikasi/Tipe → Input Jumlah Qty Fisik → Lokasi/Catatan (Opsional) → Klik "Simpan Data Fisik Gudang"
3

Unit Belum Opname

Monitoring Unit Out-of-Stock Check

  • Memantau daftar unit yang belum diperiksa beserta lokasi warehousenya.
  • Unit yang telah di-opname akan otomatis hilang dari daftar ini.
4

Impor & Ekspor

Manajemen Data Master & Laporan

  • Impor Master (File 1): Unggah data master unit utama.
  • Impor File Hari Ke-2 s/d N: Untuk penyesuaian lokasi/warehouse jika audit berlangsung beberapa hari. Unit yang tidak ada di File 1 tetap muncul tanpa merusak Rekap Audit KSU.
  • Download Hasil: Unduh Excel hasil opname unit, Excel rekap KSU, serta ZIP seluruh foto bukti fisik.
  • Reset Database: Fitur pembersihan seluruh data lokal pada perangkat.
💡 Seluruh data tersimpan offline di perangkat ini (IndexedDB) dan tersinkronisasi otomatis antar menu — tanpa memerlukan koneksi internet.
